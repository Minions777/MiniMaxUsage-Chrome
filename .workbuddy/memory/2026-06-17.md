### Post-deploy runtime bug fix (3 Chrome errors)
- Root cause: Two `\u{...}` Unicode escape sequences contained Chinese characters instead of hex code points
  - badge.js line 79: `\u{9醒}` → 醒 is not hex; correct code point is 9192
  - themes.js line 89: `\u{幻}` → 幻 is not hex; correct code point is 5E7B
- Cascading failures:
  - badge.js parse fail → importScripts() entire batch fails → fetchUsage undefined (Error 1)
  - themes.js parse fail → PMM.theme never created → getTheme undefined (Error 3)
  - Invalid Unicode escape sequence (Error 2)
- Fix: Replaced ALL `\u{...}` sequences across background/ and popup/ with direct Chinese characters/emoji literals for readability and robustness
